# Compile the audited paper

Upload the contents of this directory to Overleaf and select **main.tex** as the main document. Keep the comparison directory alongside it with results.tex and SELF_X_Algorithm_Comparison.pdf. Use pdfLaTeX. The manuscript appends the 13 all-controller XY figures from the atlas.

The repository README gives the CPU commands to regenerate the comparison data, figures, PDF atlas and the manuscript's results macros.

historical_main.tex and SELF_X_IEEE_Paper.tex preserve the pre-audit manuscript. Their experimental evidence predates the revised benchmark.
